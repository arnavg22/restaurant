## Key Points

1. **ZERO manual entry** — Razorpay detects payment automatically
2. **Real-time updates** — Customer sees confirmation instantly via WebSocket
3. **Admin gets notified** — New order appears on admin dashboard immediately
4. **UPI QR is generated by Razorpay** — Supports ALL UPI apps (GPay, PhonePe, Paytm, BHIM, etc.)
5. **Also supports cards/netbanking** — Razorpay checkout handles all methods

## Razorpay Setup

### Step 1: Create Razorpay Account
1. Go to [dashboard.razorpay.com](https://dashboard.razorpay.com)
2. Sign up with business details
3. Complete KYC verification

### Step 2: Get API Keys
1. Dashboard → Settings → API Keys
2. Generate Test keys first (for development)
3. Note down: `Key ID` and `Key Secret`

### Step 3: Setup Webhook
1. Dashboard → Settings → Webhooks
2. URL: `https://yourdomain.com/api/v1/webhook/razorpay`
3. Secret: Generate a strong secret
4. Subscribe to events:
   - `payment.authorized`
   - `payment.captured`
   - `payment.failed`
5. Activate webhook

### Step 4: Environment Variables
```env
RAZORPAY_KEY_ID=rzp_test_xxxxxxxxxx
RAZORPAY_KEY_SECRET=xxxxxxxxxxxxxxxxxxxxxxxx
RAZORPAY_WEBHOOK_SECRET=your_webhook_secret
```

## Frontend Integration (Razorpay Checkout)

```jsx
// After placing order via POST /orders, you get:
// { order: {...}, payment: { razorpayOrderId, razorpayKeyId, amount, ... } }

function openRazorpayCheckout(paymentData, onSuccess, onError) {
    const options = {
        key: paymentData.razorpayKeyId,
        amount: paymentData.amount, // in paise
        currency: 'INR',
        name: 'Cafeteria Green',
        description: `Order ${paymentData.orderNumber}`,
        order_id: paymentData.razorpayOrderId,
        
        // Prefill customer info
        prefill: {
            name: customerName,
            email: customerEmail,
            contact: customerPhone
        },
        
        // Theme
        theme: {
            color: '#4a9f6f' // Cafeteria Green brand color
        },
        
        // Success handler
        handler: function (response) {
            // Payment successful!
            // response.razorpay_payment_id
            // response.razorpay_order_id
            // response.razorpay_signature
            // 
            // NOTE: You don't need to send these to server.
            // The webhook handles verification automatically.
            // Just show "Payment successful, waiting for confirmation..."
            onSuccess(response);
        },
        
        // Modal close handler
        modal: {
            ondismiss: function () {
                onError('Payment cancelled by user');
            }
        }
    };
    
    const rzp = new Razorpay(options);
    rzp.open();
}
```

## Fallback: UPI Deep Link (No Razorpay)

If you want to avoid Razorpay entirely, the system also generates a raw UPI deep link:

```
upi://pay?pa=cafeteriagrean@paytm&pn=Cafeteria%20Green&am=360.00&cu=INR&tn=Order%20GRN-20260606-0001
```

But this requires manual verification. The Razorpay approach is recommended.
